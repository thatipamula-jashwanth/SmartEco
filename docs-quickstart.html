Step-by-Step Quickstart

I - Install SmartKNN


pip install smart-knn

II - Import and Load Data

Regression example:


from smart_knn import SmartKNN
from sklearn.datasets import load_diabetes

X, y = load_diabetes(return_X_y=True)

Classification example:


from sklearn.datasets import load_breast_cancer

X, y = load_breast_cancer(return_X_y=True)

III - Create a SmartKNN Model

Use default settings:


model = SmartKNN()

Customize neighbour count:


model = SmartKNN(k=7)

Adjust feature weighting behavior:


model = SmartKNN(alpha=0.4, beta=0.3, gamma=0.3)

Enable ANN backend for faster inference:


model = SmartKNN(backend='auto')

IV - Fit the Model


model.fit(X, y)

SmartKNN automatically detects whether the task is regression or classification based on the target variable.

V - Run Predictions

Regression output:


preds = model.predict(X[:5])
print(preds)

Classification output:


preds = model.predict(X[:5])
print(preds)

Regression returns continuous values. Classification returns discrete class labels.

Full Example - Regression


from smart_knn import SmartKNN
from sklearn.datasets import load_diabetes

X, y = load_diabetes(return_X_y=True)

model = SmartKNN(
    k=7,
    weight_threshold=0.1,
    alpha=0.4,
    beta=0.3,
    gamma=0.3,
    backend='auto'
)

model.fit(X, y)

predictions = model.predict(X[:3])
print("Predictions:", predictions)

Full Example - Classification

Using the ANN Backend

The ANN backend accelerates neighbour search by retrieving a small candidate set before exact distance refinement. This enables SmartKNN to scale efficiently to large datasets.

In some cases, accuracy may decrease slightly if the candidate pool is too small. Increasing the candidate size or adjusting backend settings can help recover recall. 


model = SmartKNN(
    k=10,
    backend="ann"
)
model.fit(X, y)

Saving & Loading a Trained Model

SmartKNN models can be saved and loaded using Python’s built-in serialization tools. This is useful for reuse in production or offline inference. 


import pickle

# Save trained model
with open("smartknn.pkl", "wb") as f:
    pickle.dump(model, f)

# Load model later
with open("smartknn.pkl", "rb") as f:
    loaded_model = pickle.load(f)

Note: Only load pickled models from trusted sources. Pickle is not secure against untrusted or corrupted files.

Best Practices

  • Encode categorical features explicitly before training SmartKNN.
  • Smaller values of k yield faster, more sensitive predictions, while larger values provide smoother and more stable results.
  • Use the ANN backend for large datasets to achieve predictable inference latency at scale.
  • Avoid extreme values for alpha, beta, and gamma; validate weight configurations on a held-out set.
  • Ensure missing values are handled consistently prior to training, especially for high-dimensional or sparse datasets.

Troubleshooting

Prediction is too slow? Enable the ANN backend
Accuracy is lower than expected? Tune alpha, beta, and gamma, increase k, or inspect learned feature weights for noise dominance.
Dimension or shape mismatch errors? Ensure the same preprocessing pipeline is applied during both training and inference.
