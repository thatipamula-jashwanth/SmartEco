Installation Guide

How to install and verify SmartKNN on your system

System Requirements

RequirementDetails
Python3.8 or newer
Operating SystemWindows, Linux, macOS
Core Dependenciesnumpy, pandas
Other Dependenciesscikit-learn, faiss (ANN)
HardwareCPU supported by default, GPU optional

Installation

Standard Installation (Recommended)


pip install smart-knn

Upgrade Existing Installation


pip install --upgrade smart-knn

Install a Specific Version


pip install smart-knn==0.2.0

Verify Installation


python -c "import smart-knn; print(smart-knn.__version__)"

Common Installation Issues

Missing or Outdated Dependencies

Ensure required numerical libraries are installed and up to date. 


pip install --upgrade numpy

Failed Building Wheel

This usually indicates an outdated build toolchain. 


pip install --upgrade pip setuptools wheel

Version Conflicts


pip install --force-reinstall smartknn

Quick Verification Script

Run the following script to confirm SmartKNN is installed and working correctly. 


from smart_knn import SmartKNN
import numpy as np


X = np.random.rand(50, 6)
y = np.random.rand(50)

model = SmartKNN()
model.fit(X, y)

print("Prediction:", model.predict(X[:3]))

Recommended Environment Setup

Using a virtual environment is strongly recommended. 


python -m venv env
source env/bin/activate   # Windows: env\Scripts\activate
pip install smart-knn

Uninstallation


pip uninstall smart-knn

Install From Source


git clone https://github.com/thatipamula-jashwanth/smart-knn
cd smartknn
pip install -r requirements.txt
pip install .
