SmartKNN Parameters

Detailed explanation of all configurable parameters in SmartKNN.

Overview

SmartKNN is fully configurable and exposes parameters that control both learning behavior and neighbour search strategy.

The weighting factors alpha, beta, and gamma influence feature weighting by adjusting the contribution of linear sensitivity, mutual information, and tree-based importance signals.

SmartKNN also supports backend selection via brute, ann, and auto modes, allowing users to balance accuracy and performance based on dataset scale.

Complete Parameter Table

Parameter Type Default Description
k int 5 Number of nearest neighbors used for prediction
weight_threshold float None Filters out features with learned weights below the threshold
alpha float 1/3 Linear sensitivity (MSE-based) weight component
beta float 1/3 Mutual information weight component
gamma float 1/3 Tree-based (RF-style) importance component for noisy data
force_classification bool | None None Forces classification mode when the target variable is numeric. If None, the task type is inferred automatically.
backend str "auto" Neighbour search backend selection: brute, ann, or auto
use_gpu bool False Enables GPU acceleration for neighbour search when supported by the selected backend.
n_jobs int -1 Number of CPU threads used for parallel computation. Use -1 to utilize all available cores.

Parameter Explanations

K - Number of Neighbours

Controls the size of the local neighbourhood used for prediction. Larger values smooth predictions, while smaller values increase sensitivity.

  • Increase when: the dataset is noisy or labels are unstable
  • Decrease when: sharp local decision boundaries exist
  • Recommended range: 5–15 for most datasets

model = SmartKNN(k=7)
weight_threshold - Feature Pruning Threshold

Removes features whose learned importance falls below the specified threshold, reducing noise and improving performance.

  • Increase when: Many irrelevant or redundant features exist
  • Decrease when: Features contribute weak but cumulative signal
  • Recommended range: 0.0 – 0.1

model = SmartKNN(weight_threshold=0.1)
alpha - Linear Sensitivity Weight

Controls the influence of linear [MSE-based] feature sensitivity during weight learning.

  • Higher values emphasize linear relationships
  • Lower values favor nonlinear and interaction-based signals

model = SmartKNN(alpha=0.3)
beta - Mutual Information Weight

Emphasizes nonlinear dependencies between features and the target using mutual information.

  • Increase for complex, nonlinear tabular datasets
  • Reduce when linear models already perform well

model = SmartKNN(beta=0.4)
gamma - Tree-Based Importance Weight

Incorporates tree-style feature importance to improve robustness on noisy or high-dimensional datasets.

  • Increase for mixed categorical and numerical features
  • Reduce for smooth, low-noise datasets

model = SmartKNN(gamma=0.4)
force_classification - Override Task Detection

Forces classification mode even when the target values appear numeric. Useful for encoded class labels. 


model = SmartKNN(force_classification=True)
backend - Neighbour Search Engine

Selects the neighbour search strategy: brute, ann, or auto. 


model = SmartKNN(backend="ann")
use_gpu - GPU Acceleration

Enables GPU acceleration for neighbour search when supported by the selected backend and available runtime. 


model = SmartKNN(use_gpu=True)

Backend Behavior

Brute backend performs an exact KNN search over the full dataset. It provides maximum accuracy but incurs higher latency on large datasets.

ANN backend uses approximate nearest neighbour indexing to retrieve a small candidate set before refinement. This significantly improves speed with minimal impact on accuracy.

Auto mode automatically selects the ANN backend when available and falls back to brute-force search otherwise. 


SmartKNN(backend="ann")
    

SmartKNN(backend="brute")
    

SmartKNN(backend="auto")

Full Example Script


from smart_knn import SmartKNN
import pandas as pd


df = pd.read_csv("data.csv")

X = df.drop(columns=["target"])
y = df["target"]

model = SmartKNN(
    k=7,
    alpha=0.4,
    beta=0.3,
    gamma=0.3,
    weight_threshold=0.1,
    backend="auto"
)

model.fit(X, y)

predictions = model.predict(X.iloc[:5])
print(predictions)

Important Notes

  • Feature weights are normalized automatically during training and do not require manual scaling.
  • Some parameters are sensitive to small changes. Tune values incrementally and validate on a held-out set.
  • The ANN backend may reduce accuracy if the candidate pool is configured too small. Increase candidate size if recall drops.
  • GPU acceleration depends on a compatible CUDA runtime and supported backend libraries (e.g., cuML or FAISS-GPU).
