SmartKNN Version History

Evolution of SmartKNN - Features, Fixes, and Planned improvements.

Overview

This page describes the progression of SmartKNN across releases, highlighting improvements in classification logic, backend engines, vectorized execution, and adaptive learning techniques.

Release Timeline

Version 0.1.0 - First Public Release

  • Regression support
  • Initial classification support [experimental]
  • Basic SmartKNN feature weighting engine
Classification behavior was experimental in this release and returned continuous values rather than discrete class labels. 

model = SmartKNN()
model.fit(X, y)
model.predict(X[:5])

Version 0.1.1 - Stability and Safety Update

  • Classification temporarily disabled to prevent ambiguous outputs
  • Regression pipeline stabilized
  • Improved consistency in feature weight learning
The classification module was internally refactored in preparation for a redesigned decision logic introduced in v0.2.0. 

model = SmartKNN() #Regression Only
model.fit(X, y)

Version 0.2.0 - Performance & Scalability Upgrade

  • Major performance improvements through vectorized execution
  • Removal of Python loops from critical distance and weighting paths
  • ANN backend introduced for fast neighbour candidate retrieval
  • Optional GPU support for neighbour search acceleration
  • Feature weight learning redesigned to scale to millions of samples
  • Classification support reintroduced with stable decision logic
This release focuses on production readiness by prioritizing predictable inference latency and scalable training behavior. 

model = SmartKNN(
    k=7,
    use_ann=True,
    backend='auto'
)
model.fit(X_train, y_train)
pred = model.predict(X_test)

Feature Progress Summary

Version 0.1.0

  • Regression: Stable
  • Classification: Experimental
  • Execution: Partially vectorized
  • ANN backend: Not available
  • GPU support: Not available

Version 0.1.1

  • Regression: Stable
  • Classification: Disabled for safety
  • Execution: Partially vectorized
  • ANN backend: Not available
  • GPU support: Not available

Version 0.2.0

  • Regression: Stable
  • Classification: Stable
  • Execution: Fully vectorized
  • ANN backend: Available
  • GPU support: Available for neighbour search

Roadmap Notes

  • The transition from the 0.1.x series to 0.2.x focuses on stabilizing classification and unifying behavior across regression and classification tasks.
  • The introduction of ANN and optional GPU-backed neighbour search enables SmartKNN to operate at production scale with predictable latency.
