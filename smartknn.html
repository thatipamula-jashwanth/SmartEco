SmartKNN: A Standalone Distance-Native Model for Fast, Interpretable Neighbor Search

What is SmartKNN?

SmartKNN is a distance-native learning model for robust and interpretable tabular machine-learning tasks, built around the principle of locality-based reasoning. Rather than assuming uniform feature relevance, SmartKNN automatically learns feature importance using a combination of statistical signals and model-based measures, allowing similarity to reflect what truly matters in the data. The framework includes automatic normalization, NaN/Inf handling, weak-feature suppression, and a feature-aware distance formulation to ensure stable behaviour on real-world datasets. By explicitly designing the distance space in which neighbour relationships are formed, SmartKNN retains the transparency and intuition of instance-based learning while delivering stronger robustness, improved accuracy, and clearer interpretability in production settings.

Why SmartKNN Exists

Many distance-based learning approaches rely on assumptions that rarely hold in real-world tabular data. Uniform feature relevance, fixed neighbourhood sizes, and unstructured distance aggregation make similarity calculations fragile in the presence of noise, redundant attributes, outliers, and heterogeneous feature scales. Under these conditions, neighbourhoods become unstable, decision boundaries fluctuate, and predictive behaviour degrades. SmartKNN was developed to address these issues by treating distance computation as a first-class design problem. The framework learns feature relevance in a supervised manner, suppresses weak or misleading signals, and adapts neighbourhood influence on a per-query basis while remaining fully interpretable. The result is a non-parametric, locality-driven model that preserves intuitive instance-based reasoning, yet behaves reliably on messy, real-world tabular datasets where rigid distance assumptions fail.

How SmartKNN Works

SmartKNN transforms distance-based learning into a robust, feature-aware framework. It preserves intuitive locality-based reasoning while adapting to real-world data:

  • Step 1 - Validate numeric data – Ensures input arrays have correct shapes and types.
  • Step 2 - Handle missing values – Automatically cleans NaN and Inf entries.
  • Step 3 - Clip outliers – Reduces extreme value impact to improve stability.
  • Step 4 - Normalize features – Standardizes scales for consistent distance calculation.
  • Step 5 - Learn feature weights – Computes importance using MSE, Mutual Information, and Random Forest gain.
  • Step 6 - Combine and normalize weights – Ensures feature importance scores are comparable.
  • Step 7 - Filter weak features – Removes features below an importance threshold.
  • Step 8 - Neighbour search & prediction – Finds nearest candidates and predicts using weighted contributions.

When to Use / When Not to Use

Use SmartKNN When
  • Data has mixed signals & noise
  • Non-linear boundaries exist
  • Tabular structured datasets
  • Imbalanced or multi-class targets
  • Interpretability matters
Avoid SmartKNN When
  • High-dimensional sparse vectors (raw text)
  • Very small datasets
  • Neural feature extraction is required
  • Pure image / audio raw pixel inputs
  • You need generative outputs

API & Code Snippet

import pandas as pd
from smart_knn import SmartKNN

df = pd.read_csv("data.csv")
X = df.drop("target", axis=1)
y = df["target"]

model = SmartKNN(k=5)
model.fit(X, y)

sample = X.iloc[0]
pred = model.predict(sample)
print("Prediction:", pred)
