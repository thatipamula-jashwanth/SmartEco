SmartKNN Feature Selection Logic

How SmartKNN learns what matters & what doesn’t.

Introduction

Vanilla KNN treats all features equally. This works only when every feature contributes equally to the target.

In real world datasets especially noisy, irrelevant, or high dimensional ones this assumption fails badly.

SmartKNN solves this by learning adaptive feature weights before computing distances, so unimportant dimensions do not distort predictions.

Overview of the SmartKNN Feature Pipeline

I. Normalization & Imputation

Missing values filled & features scaled to comparable magnitudes.

II. Feature Weight Learning

MI, RF, MSE statistics merged into a unified weight vector.

III. Feature Masking & Cleanup

Low impact dimensions removed for speed and accuracy.

Mathematical Definition of Feature Weights

The SmartKNN weight vector W is computed as a blend of multiple metrics:

W = α × MI + β × RF + γ × MSE

MI: Mutual Information
RF: Random Forest impurity scores
MSE: Regression-based sensitivity
SmartKNN automatically normalizes α + β + γ = 1 even if user input does not.

ComponentPurposeWorks Best When
MICaptures Non linear dependencyMedium & high dimensional datasets
RFTree based split importanceNoisy mixed datasets
MSELocal linear sensitivitySmooth continuous regression problems

Feature Masking [Dropping Useless Features]

Features whose learned weight falls below the threshold are removed:

model = SmartKNN(weight_threshold=0.05)

This drastically improves speed and accuracy on Noisy, High-Dimensional datasets.

Weighted Distance Computation

After learning weights, SmartKNN computes distances using:

d(x, q) = √( Σⱼ wⱼ × (xⱼ − qⱼ)² )

Intution

  • Important features → high wⱼ → space stretches → more influence
  • Useless features → low wⱼ → space compresses → almost ignored

Real-World Examples

Regression


model = SmartKNN(
    k=5,
    weight_threshold=0.1,
    alpha=0.4,
    beta=0.3,
    gamma=0.3
)
model.fit(X_train, y_train)
pred = model.predict(X_test)

Classification


model = SmartKNN(
    k=7,
    task="classification",

    alpha=0.4,
    beta=0.3,
    gamma=0.3
)
model.fit(X_train,y_train)
pred = model.predict(X_test)

Advanced Notes

  • Correlation collapse: Mutual Information (MI) reduces the risk of overweighting collinear features by capturing shared information rather than raw correlation.
  • Tree impurity: The Random Forest (RF) component captures feature interactions and performs well on noisy or categorical-like distributions.
  • Stabilization: Learned feature weights stabilize high-K predictions by suppressing low-signal dimensions.
  • ANN backend: Feature weights constrain the effective search subspace, improving recall during approximate neighbour retrieval.

Warnings & Limitations

Feature weight learning can be computationally expensive during training on datasets larger than ~1M rows. Inference remains fast due to vectorized distance computation.
Extremely high-dimensional or sparse datasets may still require external feature reduction prior to training.
Poor tuning of α, β, and γ can significantly degrade accuracy. Always validate weight configurations on a held-out dataset.
Overly aggressive feature masking can lead to underfitting. Inspect learned weights before applying strict thresholds.

Best Practices Checklist

  • Ensure categorical features are properly encoded before training.
  • Tune α, β, γ based on dataset characteristics and validate on a held-out set.
  • Inspect weights_ after fitting to verify that important features are emphasized.
  • Enable the ANN backend for large datasets to reduce neighbour search latency.
